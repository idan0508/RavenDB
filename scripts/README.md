# Scripts

This folder contains the Python data collection and import scripts used by the Helpdesk project.

Common configuration (all scripts that talk to RavenDB):
- RAVENDB_URL (default: http://100.68.0.72:8080)
- RAVENDB_DATABASE (default: HelpdeskDB)

## Python scripts

- collect_discussions.py
  Collects GitHub Discussions from ravendb/ravendb and writes JSON files into scripts/collected_discussions.
  Requires GITHUB_TOKEN (set in environment or scripts/.env).

- collect_docs_sitemap.py
  Scrapes docs.ravendb.net via sitemap and writes directly to RavenDB.
  Supports --ravendb-url, --database, --collection, --versions, --all-versions, --include-guides.

- import_to_ravendb.py
  Imports the latest JSON files from scripts/collected_discussions into RavenDB.

- failed_urls.txt
  Output file generated by collect_docs_sitemap.py when some URLs fail.

- collected_discussions/
  Output directory for JSON data (discussions_latest.json, documentation_latest.json, etc.).

- FINAL_PRODUCTION_READY.md
  Longer checklist and notes for end-to-end runs.

## C# Google Groups MBOX importer

The Google Groups MBOX importer lives in HelpdeskAgent/MboxImporter.cs and is invoked from HelpdeskAgent/Program.cs.

Run example:
  dotnet run --project HelpdeskAgent -- --import-mbox "C:\path\to\file.mbox"

Optional environment variable:
- MBOX_PATH (used if the path is not passed after --import-mbox)
